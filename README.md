# Oro Rojo — Spanish Cookbook

Concept landing page for a fictional Spanish cookbook, made as a showcase project by **Fata Digital**.

## What's inside

```
index.html        the page
css/style.css     all styles and animations
js/main.js        chapter spines, recipe tabs, newsletter demo
images/           book cover and food photos
```

Plain HTML, CSS and JavaScript — no build step. Open `index.html` in a browser to view it.

## Publish on GitHub Pages

1. Upload the contents of this folder to a new repository (keep `index.html` at the root).
2. Repository → **Settings → Pages** → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Notes

- The book, author, phone number and email are fictional — this is a design concept, not a real shop.
- Order buttons and the newsletter form are for show and don't send anything.
- Scroll-driven handwriting effects work in Chrome and Edge; other browsers show the text without the animation.
